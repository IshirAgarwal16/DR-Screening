ABOUT THE PLATFORM

Supporting More Accessible Diabetic Eye Screening

DR Screening brings together fundus image validation, image quality assessment, AI-based retinopathy screening, and explainable AI in one screening workflow for healthcare workers and doctors.

KEY FEATURES

Built Around the Screening Workflow

📷

Fundus Validation

The system first checks whether the uploaded image appears to be a retinal fundus image.

🔍

Image Quality Assessment

Image quality is checked before screening so unsuitable images can be identified early.

🧠

AI-Based Screening

The AI model estimates the severity of diabetic retinopathy from the retinal image.

🔥

Explainable AI

Grad-CAM highlights image regions that influenced the model's prediction.
